# 🃏 Magic Inventory

Magic Inventory is a desktop application designed to manage a **Magic: The Gathering card collection**.

🚧 This project is being developed as a **personal learning project** to improve skills in:

- 🐍 Python development
- 🔗 API integration
- 🖥️ GUI design
- 🗄️ Database management
- 🤖 Artificial Intelligence integration

The application allows users to search cards using the **Scryfall API**, store them locally and visually manage their collection.

# ✨ Current Features

The application currently includes:

🔍 **Card Search**

- Search cards using the Scryfall API
- Display card image and card information

📦 **Collection Management**

- Add cards to your personal collection
- Set quantity for each card
- Store collection in a SQLite database
- Automatic duplicate detection (card quantities merge)

📊 **Collection Visualization**

- View collection in a table with card images
- Responsive graphical interface

Future versions will include a more visually appealing and intuitive interface.

## 🔎 Advanced Collection Search

Advanced filtering tools will be added to allow searching the collection by different parameters such as:

- Card name
- Edition / set
- Quantity
- Card type
- Rarity

This will make managing large collections much easier.

---

## ❤️ Life Counter for Matches

A life counter feature will be integrated into the application to allow players to use it during matches.

Planned functionality includes:

- Multiple player life counters
- Commander life tracking
- Quick reset and adjustments
- Simple gameplay interface

---

## 🤖 AI Card Interaction Assistant

One of the long-term goals of the project is to include an **AI assistant capable of explaining card interactions**.

Possible capabilities include:

- Explaining interactions between multiple cards
- Clarifying complex rules interactions
- Suggesting possible combos
- Providing rule references

This feature will explore the integration of **AI and natural language processing** with card databases.
